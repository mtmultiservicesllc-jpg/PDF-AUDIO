# GRC Drive Audio Player 🚗🎧

An in-car, hands-free audio review web application designed for listening to GRC interview preparation materials, frameworks (CMS ARC-AMPE, HITRUST r2, NIST SP 800-53, CMMC), and custom uploaded PDFs while driving.

## Features
- **CarPlay & Bluetooth Compatible**: Plays native background audio that works with car steering wheel controls and phone lock screens.
- **Pre-Loaded Audio Episodes**: Features the 4-question mock interview for Random Bit / State Medicaid GRC consulting.
- **Universal PDF Extractor**: Drag and drop or browse any PDF file from iPhone Files / Google Drive to have it read aloud instantly using browser speech synthesis.
- **Driver-Friendly High-Contrast UI**: Big tactile buttons (Play/Pause, Skip 15s, Replay 15s, Speed 1.0x / 1.25x / 1.5x).

## Deployment
- Ready to deploy to **Vercel** with 1 click.
- Ready to host on **GitHub Pages**.
